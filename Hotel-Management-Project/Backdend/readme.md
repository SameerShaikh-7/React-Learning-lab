# Hotel Room Management API 🏨

A robust and modular RESTful API backend for managing hotel room inventory. Built specifically to handle operations like adding new rooms, updating availability, and fetching room details seamlessly.

## 🚀 Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB
* **ODM:** Mongoose
* **Environment Management:** dotenv

## ✨ Key Features
* Full CRUD (Create, Read, Update, Delete) capabilities.
* Partial document updates utilizing the `PATCH` method for optimized data handling.
* Clean, modular project architecture (`config`, `models`, `routes`, `controllers`).
* Secure handling of database credentials via `.gitignore` and `.env`.
